# 01 CONCEPT — MMSP

## Background

기존 생산관리 업무는 대형 Excel 관리대장에 여러 영업팀의 PO 데이터를 통합하고, 다수의 수식과 수작업 입력을 결합하여 운영하고 있습니다.

워크북이 커지면서 계산량과 의존 수식이 증가했고, 여러 부서가 각기 다른 진행 정보를 입력해야 하기 때문에 성능, 데이터 지속성, 다중 사용자 동기화 문제가 커졌습니다.

## Goal

기존 Excel 사용자 경험을 최대한 유지하면서 데이터와 계산 책임을 Excel 수식에서 분리합니다.

목표 구조:

```text
SharePoint = 중앙 저장 / 배포 위치
Excel      = 사용자 Client
Access     = 영속 데이터 / 계산 Engine
```

사용자는 복잡한 기술 구성요소를 직접 다루지 않고 Excel Client에서 업무를 수행할 수 있어야 합니다.

## Primary Requirements

- 중앙 데이터가 지속적으로 보존되어야 합니다.
- 최신 PO 목록을 다시 받아도 기존 수작업 진행 정보가 복원되어야 합니다.
- 여러 부서가 서로 다른 진행 필드를 수정할 수 있어야 합니다.
- 저장 시 전체 시트 덮어쓰기보다 변경된 레코드/필드 중심으로 동기화해야 합니다.
- 충돌과 동시 저장을 통제해야 합니다.
- 일반 사용자는 Access UI, VBS, VBA 편집기를 직접 사용할 필요가 없어야 합니다.

## Technology Boundary

현재 프로젝트에서 사용하는 핵심 기술 범위:

- Microsoft SharePoint
- Microsoft Excel
- Microsoft Access

추가 서버나 별도 데이터 플랫폼을 기본 전제로 두지 않습니다.
